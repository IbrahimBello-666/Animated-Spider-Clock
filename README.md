An interactive, web-based analog clock face featuring an animated spider theme, mechanical gear graphics, and dynamic JavaScript clock logic.

## File Structure

```text
├── index.html    # Main HTML structure and clock container
```

<br>

## *Interactive Spider Clock Face*
An interactive, web-based analog clock face featuring an animated spider theme, gears, and custom typography. <br>
Built using standard web technologies (HTML5, CSS3, and JavaScript).

---

# Key Features
•Live Analog Time: Accurately renders hours, minutes, and seconds in real-time.<br>
•Interactive Design: Custom spider and web aesthetics integrated directly into the clock hands and center pivot.<br>
•Gear Architecture: Gear and web graphics layered in the background to create depth.<br>
•Lightweight & Responsive: Fits cleanly across mobile and desktop displays without heavy external dependencies.

---

## Tech Stack
•HTML5: Structure and canvas/DOM elements.<br>
•CSS3: Styling, layout positioning, and dynamic animations.<br>
•JavaScript: Math-driven rotation and live time tracking logic.<br>
